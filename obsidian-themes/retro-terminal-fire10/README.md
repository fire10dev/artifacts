# Retro Terminal — fire10.dev edition

An Obsidian theme: the **Retro Terminal** theme recolored with the
[fire10.dev](https://fire10.dev) palette. Terminal identity is kept
(full monospace, square corners, blinking block cursor, CRT scanline);
only colors, shadows and borders change.

## Two palettes

- **Dark — Forest Phosphor:** lime + sun accents on deep forest green.
- **Light — Warm Paper:** forest-green ink, lime/sun/coral accents on cream paper,
  with the fire10 hard-offset shadow and paper grid + sun-glow.

## Install

Copy this folder into your vault at:

```
<vault>/.obsidian/themes/Retro Terminal/
```

then pick **Retro Terminal** under Settings → Appearance → Themes and reload.
